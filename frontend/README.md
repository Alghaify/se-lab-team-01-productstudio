# واجهة ProductStudio

هذا المجلد مخصص لواجهة المحرر. ابدأ بتطبيق التخطيط الموجود في `docs/SRS.md`، ثم اربط زر الرفع بـ `/api/images/upload`.

المكونات المقترحة:
- `EditorLayout`: التخطيط العام.
- `Toolbar`: أدوات الرفع والتحويل والفلاتر والرسم.
- `CanvasStage`: عرض الصورة والعناصر.
- `PropertiesPanel`: القيم المنزلقة والخصائص.
- `LayersPanel`: الطبقات والشفافية والترتيب.
- `ExportDialog`: الصيغة والجودة والمقاس.
