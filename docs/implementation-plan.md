# خطة التنفيذ وما يجب إكماله

## المرحلة الأولى: تجهيز المستودع
أنشئ المستودع والملفات الموجودة في هذه الحزمة، ثم املأ أسماء الفريق وأضف رابط المستودع في README.

## المرحلة الثانية: الواجهة
ابنِ شاشة البداية وشاشة المحرر: شريط علوي، شريط أدوات، Canvas، لوحة خصائص، ولوحة طبقات. ابدأ بواجهة ثابتة ثم اربط الأحداث تدريجيًا.

## المرحلة الثالثة: العمليات الأساسية
نفّذ الرفع والمعاينة والقص والحجم والدوران والقلب، ثم أضف التراجع والإعادة. لا تنتقل للفلاتر قبل نجاح هذه العمليات.

## المرحلة الرابعة: المعالجة
أضف Pillow وOpenCV في الخادم، واكتب اختبارات صغيرة لكل عملية. احتفظ بصورة الأصل، وأعد نسخة جديدة لكل تعديل.

## المرحلة الخامسة: الطبقات والميزات الإبداعية
أضف الرسم والنص والشفافية والخلفيات وإزالة الخلفية اليدوية والظل. هذه الميزات ترفع جودة العرض لكنها تأتي بعد النواة.

## المرحلة السادسة: الاختبار والتوثيق
نفّذ حالات `docs/test-cases.md`، التقط صورًا للشاشات، حدّث `AI_Log.md`، وأغلق Issues المرتبطة بعد المراجعة.

## ما يجب عليك تعبئته يدويًا
1. أسماء أعضاء الفريق وأدوارهم.
2. اسم المستودع ورابطه.
3. الحد الأقصى لحجم الصور حسب جهازكم.
4. هل ستنفذون React كاملًا أم JavaScript بسيطًا.
5. صور الخلفيات وقوالب المنتجات.
6. نتائج الاختبار الفعلية ولقطات الشاشة.
7. سجل استخدام أدوات الذكاء الاصطناعي.
