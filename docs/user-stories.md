# قصص المستخدم ومعايير القبول

## US-01: رفع صورة
**بصفتي** مستخدمًا، **أريد** رفع صورة، **حتى أتمكن** من بدء تحريرها.

### Acceptance Criteria
- Given وجود شاشة البداية، When يختار المستخدم ملفًا مدعومًا، Then تظهر الصورة في Canvas.
- Given ملف غير مدعوم، When يحاول المستخدم رفعه، Then تظهر رسالة توضح الصيغ المسموحة.

## US-02: التحويل الهندسي
**بصفتي** مستخدمًا، أريد القص وتغيير الحجم والدوران والقلب، حتى أجهز الصورة للمقاس المطلوب.

### Acceptance Criteria
- تُحفظ نسبة الأبعاد عند تفعيل خيار الحفاظ عليها.
- تُضاف كل عملية ناجحة إلى سجل التراجع.
- تُرفض الأبعاد الصفرية أو السالبة.

## US-03: الفلاتر وعمليات البكسل
**بصفتي** طالبًا، أريد تطبيق الفلاتر وعمليات البكسل، حتى أشرح الفرق بين المعالجة المختلفة.

### Acceptance Criteria
- تظهر معاينة قبل التطبيق النهائي.
- يمكن تغيير شدة الفلتر ضمن مجال محدد.
- يمكن التراجع عن العملية وإعادتها.

## US-04: الطبقات والدمج
**بصفتي** مستخدمًا، أريد رفع صورتين كطبقتين، حتى أركب صورة المنتج فوق خلفية.

### Acceptance Criteria
- تظهر كل صورة في طبقة مستقلة.
- يمكن تحريك الطبقة وتغيير شفافيتها وإخفاؤها.
- يمنع النظام دمج طبقة مقفلة دون تنبيه.

## US-05: التصدير
**بصفتي** مستخدمًا، أريد تصدير الصورة بصيغة محددة، حتى أستخدمها خارج التطبيق.

### Acceptance Criteria
- يدعم التصدير PNG وJPG وWEBP.
- يمكن تحديد الجودة والمقاس.
- تظهر رسالة نجاح أو خطأ مفهومة.
